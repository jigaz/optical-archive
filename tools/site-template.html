How to burn a disc, kept for whoever needs it next.

Standards, drive command sets, file-system specifications and open-source burning software for CD, DVD and Blu-ray. When a document’s license lets us, we keep a verbatim copy with its checksum. When it doesn’t, we link to the original and ask the Internet Archive to snapshot it.

This archive tracks {{COUNT}} items, {{KEPT}} of which may be copied. A monthly job re-checks every link, downloads fresh copies, records any that changed, and publishes them as a release.

Reading the tables

Copy kept here
A verbatim copy from our latest mirror, with the first digits of its SHA-256 checksum. The full sums are in each release’s SHA256SUMS file.
Link only
The license doesn’t allow copies, so we link to the publisher and to a Wayback Machine snapshot.

Drives

The behaviour of real drives (which discs they write, at what speeds, and what goes wrong) isn’t written down anywhere. We’re collecting it as open data in drives/. To add yours, follow Report a drive.

Something missing?

Open an issue or a pull request on GitHub with the document, where it’s published, and its license. Copies are only kept when the license clearly allows it.
